# Portfolio Dynamique

## Présentation

Ce projet a été réalisé dans le cadre de la SAE 4.02 du BUT Informatique.

L'objectif était de concevoir un portfolio dynamique permettant de présenter des projets, des compétences et un parcours professionnel à travers une interface moderne et responsive. Une partie administration permet également de gérer le contenu du site.

## Fonctionnalités

### Partie publique

* Présentation du profil
* Affichage des projets
* Présentation des compétences
* Formulaire de contact
* Interface responsive

### Partie administration

* Authentification administrateur
* Gestion des projets
* Gestion des catégories
* Gestion des réseaux sociaux
* Gestion des contenus du portfolio

## Installation

1. Cloner le dépôt :

```bash
git clone <url-du-repository>
```

2. Configurer la base de données MySQL.

3. Importer le fichier SQL fourni.

4. Configurer les paramètres de connexion dans le projet.

5. Lancer le serveur local.
